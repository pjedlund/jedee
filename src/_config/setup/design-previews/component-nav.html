Main nav

The post-type mega-menu, running the site's own nav-menu.js — the MENU button is injected from the template below, so the disclosure really opens, closes on Escape, and closes on a click outside.

Without JS no button exists and the panel is a plain visible list of links. That is the fallback, not a degradation — the layered pattern is Manuel Matuzović's. The counts here are stand-ins; on the site they come from each collection's length.
