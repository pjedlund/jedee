Site footer

Two clusters that wrap independently — the licence and page links, then the platform icons. Both are labelled <nav> landmarks.

The platform links carry rel="me", which is how IndieAuth and the rest of the IndieWeb verify that these profiles are the same person. They are icon buttons, so each has a visually-hidden label and a tooltip that opens upward.
