Prose

The .prose block — running text at a 60ch measure, old-style figures, and the element styles that come from global-styles.css without any class at all.

A second-level heading

Body copy sits at a 60ch measure with text-wrap: pretty. The numerals are old-style by default — 1234567890 — because running text reads better with figures that have ascenders and descenders, the way lowercase letters do.

Links are underlined in orange and darken on hover, with the thickness fixed so nothing shifts. An abbr switches back to lining figures, and inline code drops old-style figures entirely because Source Code Pro has them too.

Depth is tonal before it is spatial. A surface lifts by changing value, not by casting a shadow — and where a shadow does appear, it is doing a job no tone could.

Johan Edlund, on the JEDEE design system
