Tooltip

Adapted from arielsalminen.com's header tooltip, retokenized and given a focus-visible trigger.

A label under an icon-only control, shown on hover and on keyboard focus. Content comes from data-tooltip — but the accessible name still has to be a real .visually-hidden label, because generated content is not a reliable accessible name. Hover or tab to the buttons below.
