the same 60ch box holding running text — characters per line, spaces included

Line length is the number of characters on one line of running text, spaces included. Too long, and the eye loses its place on the way back to the start of the next line; too short, and it has to jump back so often that the reading rhythm breaks. A max-width in ch does not set that number directly, because running text is full of narrow letters and spaces.
