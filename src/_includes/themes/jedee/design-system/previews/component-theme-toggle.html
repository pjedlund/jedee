Theme toggle

Adapted from Adam Argyle's web.dev theme switch (MIT), retokenized.

It shows the current theme — sun in light, moon in dark — and morphs between them. Click it; the whole page follows, because the theme lives on <html data-theme>.

The SVG is decorative; the accessible name is the visually-hidden label, and the state rides on aria-pressed. The visible tooltip follows the theme ("Show dark mode" / "Show light mode") while the accessible name deliberately does not — and there is no title, or two tooltips would show at once.

On the site this sits in an <is-land on:idle> — a toggle that cannot run should not appear — and the real script also writes the choice to localStorage and updates the theme-color meta. This preview toggles only the page.
